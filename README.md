# @local/dsh-mcp-manager

**DSH MCP Manager** — manage DeepSeek Harness (DSH) global MCP servers right inside the DSH web settings page.
Entries live in a managed `- insert:` block of `$DSH_HOME/cordis.patch.yml` (defaults to `~/.dsh/cordis.patch.yml`)
and hot-reload into every session after save.

## English

- **Out-of-tree double-sided plugin**: the host half (`lib/index.js`) registers prefix routes
  (`/mcp-manager/api/state|create|update|delete`) on DSH's built-in HTTP service. Loopback-only access,
  in-process mutex + official cross-process writer lock, revision conflict detection, atomic writes
  (same-dir tmp + fsync + rename).
- **Browser half** (`lib/client.js`) is a factory bundle injected into the settings page ("MCP Servers" section):
  card list, add/edit forms (stdio: command/args/env; streamable-http: url/headers/env), delete confirmation,
  zh/en dictionaries with zh as the source of truth. `lib/ui.js` is a host-side empty placeholder.
- **Narrow parser**: it only understands the canonical layout generated by this package plus user manual
  comments. Entry segments of other plugins whose shape does not match stay *opaque* and are preserved
  byte-for-byte; an unintelligible top-level structure makes the whole file refuse reads/writes
  (`unparsable`). Values pass strict sanitization (no quotes, control characters, leading/trailing
  whitespace, `": "`, `{}[],#`, etc.).
- Original build specifications (host contract / client contract / build spec) are kept under
  [`docs/specs/`](docs/specs/).

## 中文

在 DSH 的 Web 设置页内管理**全局 MCP 服务器**清单。数据落在 `$DSH_HOME/cordis.patch.yml`
（未设 `DSH_HOME` 时即 `~/.dsh/cordis.patch.yml`）的受管 `- insert:` 块中，保存后随 DSH
热重载自动挂载。

- 树外双面插件：**宿主半** `lib/index.js` 在内置 HTTP 服务上注册 `/mcp-manager` prefix 路由，
  提供 `GET api/state` 与 `POST api/create|api/update|api/delete`；仅接受回环地址（127.0.0.1/
  ::1），写操作带进程内互斥锁与 revision 冲突检测，落盘为同目录 tmp + fsync + rename 原子替换。
- **浏览器半** `lib/client.js` 是 factory bundle，在设置页注入「MCP 服务器」分区（order 55）：
  卡片列表、添加/编辑表单（stdio: command/args/env；streamable-http: url/headers/env）、删除确认。
  zh 双语词典以 zh 为真源。`lib/ui.js` 为宿主侧空座。
- 解析器是**窄解析**：只认本包生成的规范布局 + 用户手工注释；同文件里其他插件的条目段若形状
  不匹配，会保持“不透明”并原样字节保留，绝不破坏；出现无法理解的顶层结构时整体拒绝读写
  （`unparsable`）。值经宁严勿损 sanitize（拒绝引号、控制字符、首尾空白、`: `、`{}[],#` 等）。

## 安装在哪

由指挥官安装进 DSH 主目录（本包不自我安装）：包体置于 `%DSH_HOME%` 的插件目录下
（如 `~/.dsh/plugins/<scope>/@local/dsh-mcp-manager`，以实际安装脚本为准）。

注意：client-modules 扫描器要求客户端包在 exports 中显式暴露 `"./package.json"`，
本包已按此约定导出，以完成 `dsh.client` 平台发现。

## 自测

构建时三项自测已在系统 temp（`%TEMP%\dsh-mcp-plugin-tests\`）真实执行并通过。
以下命令均假设当前目录为包根（测试脚本构建期生成于 temp，不随仓库分发）：

```powershell
node --check lib\index.js
node --check lib\client.js
node "%TEMP%\dsh-mcp-plugin-tests\parser.roundtrip.test.mjs"        # 真实文件(只读) round-trip + 增改删字节恢复
node "%TEMP%\dsh-mcp-plugin-tests\e2e.http.test.mjs"                # HTTP CRUD 端到端（DSH_HOME 指向 temp）
node "%TEMP%\dsh-mcp-plugin-tests\atomic.interop.test.mjs" local    # 原子写：回退路径
# 官方包命中路径需临时 junction（用后即删）：
#   New-Item -ItemType Junction node_modules\@deepseek-ai\dsh-atomic-write `
#     -Target %USERPROFILE%\.dsh\profiles\node_modules\@deepseek-ai\dsh-atomic-write
node "%TEMP%\dsh-mcp-plugin-tests\atomic.interop.test.mjs" official
```

风险提示：解析器刻意窄化——手工把受管段改成非常规缩进/键名会使其“不透明”而不再出现在 UI 中
（字节仍保留）；配置写入方的并发编辑依赖 mtime 缓存与单机假设，不做跨进程加锁。
